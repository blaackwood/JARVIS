# Contributing

Thanks for helping improve JARVIS.

- Keep original JARVIS code separate from third-party Skills, libraries, models,
  engines, fonts and assets.
- Do not add credentials, user memory, conversation history, screenshots,
  task state, local databases, logs, or personal project files.
- Preserve every upstream licence and copyright notice when adding third-party
  material. Do not copy a Skill or asset when its redistribution rights are
  unclear; link to the original source instead.
- Add or update tests for behaviour changes. Report which tests actually ran
  and which require optional services or platform-specific facilities.
- Do not claim a capability is available by default when it needs an account,
  external binary, local permission, model download, or additional setup.
- Use SECURITY.md for vulnerability reports; do not publish secrets or
  exploitable details in public issues.
